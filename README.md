# Xiaotian Liu — Academic Website

This repository contains the source for Xiaotian Liu's personal academic website.

## Run locally

Install Ruby and Bundler, then run:

```powershell
bundle install
bundle exec jekyll serve
```

Open <http://localhost:4000> in a browser. Jekyll rebuilds the site automatically after source files change.

## Main content

- Biography: `_pages/about.md`
- News: `_news/`
- Publications: `_bibliography/papers.bib`
- Teaching: `_teachings/`
- Profile photo: `assets/img/xiaotian-liu.jpg`
- CV: `assets/pdf/xiaotian-liu-cv.pdf`
